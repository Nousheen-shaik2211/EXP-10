# EXP-10
# Chain-of-Thought Prompting for Math Reasoning

## Aim
To compare direct prompting with Chain-of-Thought (CoT) prompting on a multi-step math word problem.

## Problem Statement
A farmer has 15 cows, buys 7 more, and then sells half of his cows. Determine how many cows remain.

## Technologies Used
- Python
- Groq API
- OpenAI Python SDK
- Google Colab

## Model
`llama-3.3-70b-versatile`

## Methodology
1. Define the math word problem.
2. Send the problem directly to the LLM.
3. Send the same problem with a step-by-step instruction.
4. Extract the final numeric answer from each response.
5. Compare each answer with the expected result.

## Expected Calculation
- Initial cows: 15
- After buying: 15 + 7 = 22
- After selling half: 22 - 11 = 11
- Expected answer: 11 cows

## Conclusion
The experiment compares the answers generated by direct and CoT prompting. A single example demonstrates the methods but cannot establish general accuracy improvements.

## How to Run
1. Install dependencies using `pip install -r requirements.txt`.
2. Add `GROQ_API_KEY` to Google Colab Secrets.
3. Run `experiment.py`.
